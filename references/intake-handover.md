# 接入、费用前置与交付

## 首次了解情况

一次确认下列必要信息；现有会话已经回答的不要重复问。

| 项目 | 确认内容 |
| --- | --- |
| 目标 | 免费使用或需要订阅；网页、桌面、手机哪些需要 |
| 设备 | Mac/Windows 型号与版本，Android/iPhone 版本；手机是否可通过 USB 辅助操作 |
| 现有资源 | 可用网络、VPS、客户端、浏览器、可控邮箱/Google 账号；只问有无，不要凭据 |
| 服务条件 | 参考官方支持地区、年龄和账号要求；网络出口不能替代本人资格 |
| 旧故障 | 是否存在原有配置、账号限制、网络冲突或登录残留；不要全量清理浏览器 |
| 付款 | 订阅前确认卡组织/发行地区/线上订阅能力，或可用 App 商店支付方式；不采集卡号 |
| 可选项目 | 是否需要本地自检面板、持续提醒、应用联网限制；默认关闭 |

先确认客户的真实需求，不因教程包含某环节就强制购买全部服务。若只需已有设备免费登录，可复用现有已核实配置。订阅条件暂不具备时说明阻塞点，客户可以选择先完成免费路线。

## 金钱与账户边界

VPS、软件、账号与订阅由客户本人选择、持有、支付并保留账单。指导服务不收取银行卡数据，不把服务费与第三方余额混在一起。付款前展示当前商户、实际价格、币种、账期、自动续费与取消入口，由客户确认后本人完成。

无法验证的商家宣传不作为依据；“美国老号”“低风险 IP”等标签不能证明账号稳定。以本人可控制和恢复的账号为前提，不提供共享账号或替客户持有恢复方式。

## 操作前的恢复办法

1. 记住当前正在使用的网络工具和恢复入口，只保存脱敏状态。
2. 对将修改的设置做本机备份；涉及配置文件要按秘密文件保管，不能提交仓库。
3. 服务器重装会清空系统盘，先核对是否新服务器、备份与明确授权。
4. 网络扩展、USB 调试、防火墙等权限按需授予。系统密码、锁屏解锁、验证码由客户本人处理。
5. 涉及连接中断时，一次只改变一个变量；助手依赖此网络时准备不依赖聊天的恢复步骤。未获同意不做故障注入。

观察到微信、浏览器和助手同时失联，先恢复整机网络再排查服务，不直接判断为 Claude 账号问题。恢复成功不等于根因已定位。

## 可选：本地自检面板

仅在客户需要时提供。可按当前客户自己的基线检测本机端口、代理进程、抽样出口、时区和连接状态，汇总外部检测入口。面板不是安装和登录的必经步骤。

先说明范围并选择：不需要、只要手动检测入口、需要本地自动面板。若需要开发面板，以客户本机保存的基线实现，不复制其他客户的 IP、路径、令牌和配置。只监听本机回环地址，不开放公网。默认不发送对话、不消耗模型额度，不读取聊天和卡信息。

状态采用已核实/需注意/未核实/异常。抽样出口一致不代表全部流量都通过代理；DNS 解析器地址不必等于 VPS 地址。没有独立依据时保留未知，不自动把异常值设为新基线。只在页面可见时轮询，持续后台监控需另行明确选择。

## 可选：应用限制与断线保护

这不属于默认安装。先确认客户是否希望关闭 VPN 后整机断网，或只限制某个应用。普通浏览器、应用子进程、被调用的工具可能使用不同路径，不承诺“只限制一个主程序就覆盖所有动作”。

断线保护按当前系统实测；无法测试或系统不支持时记录限制并取得客户接受。不能因为有 VPN 图标就认定保护生效，也不能把 DNS 例外称为所有流量禁止直连。若增加限制引起其他应用异常，恢复改动前状态再分析。

## 交付清单

- 当前客户需要的平台已分别核验，网络出口与预期一致。
- Claude 官方应用或网页已登录，并由客户确认可以正常使用。
- 订阅目标：支付记录和同一账号的权益已核对；未完成则明确保留待处理。
- 已说明启动顺序、日常使用入口、关闭代理的影响和网络恢复步骤。
- 个人凭据/账单由客户保存，指导记录只包含脱敏结论。
- 可选功能是否安装、检测覆盖范围、已知限制明确可查。
- 向客户说明首次交付后提供 14 天使用答疑、最多 2 次预约远程协助；具体服务约定以购买时双方确认为准，不用该次数免除服务方自身操作错误的处理责任。

交付记录写清完成日期、设备分支、免费/订阅目标、通过依据、未完成事项和对应恢复动作。后续发现问题，先从原记录恢复上下文，不让客户重新提供全部资料。

# Claude 使用指导 · 客户交付版

从设备与付款条件确认开始，按步骤完成网络配置、浏览器准备、账号登录和订阅指导。支持 **Mac、Windows、Android、iPhone**，可随时保存进度继续。

## 从这里开始

把本仓库链接和下面这句话一起发给能够读取网页、操作本机或指导操作的 AI 助手：

> 请读取这个仓库的 SKILL.md 和它引用的文档，按我的设备逐步执行。先确认现有条件，再安装配置；每一步以实际结果为准，保存不含隐私的进度。账号、验证码和付款由我本人操作。可选自检面板和防火墙先问我是否需要。

AI 如果不能读取 GitHub：点页面上的 **Code → Download ZIP**，解压后把文件夹交给它。不会自动操作电脑的 AI 也可以根据文档逐步指引；链接本身不会获得电脑控制权。

支持本地 Skill 的工具可以按其安装方式安装整个仓库文件夹，并调用 `$claude-client-guide`。不要只复制 SKILL.md，引用的文档和脚本也需要保留。

## 准备什么

- 设备类型、系统版本，以及现在是否已有可恢复使用的网络连接。
- 自己能够控制、收信和恢复的邮箱或 Google 账号。**Google 账号不是注册 Claude 的唯一入口。**
- 如需要订阅，先确认可用的付款方式、账单信息和预算，再购买额外服务。
- 账号、VPS 和订阅均由客户本人持有和支付；不需要把密码、2FA 密钥、卡号或安全码交给指导人员。
- 先查看 [Claude 官方可用地区](https://support.claude.com/en/articles/8461763-where-can-i-access-claude)。网络出口在某地区不等于本人满足服务资格。

## 保存进度（给执行助手）

可选的本地工具只记录检查结果，**不会安装软件、修改网络、登录账号或付款**。使用 Python 3.9 或更新版本；没有 Python 时可使用同样字段的本地文字记录，无须为了阅读教程安装运行环境。

```sh
python3 scripts/workflow.py init --computer mac --phone android --goal free
python3 scripts/workflow.py next
python3 scripts/workflow.py status
```

Windows 可把 `python3` 换成 `py -3`。使用前运行 `python3 scripts/workflow.py --help` 查看完整参数。数据保存在本机 `.local/`，不要上传它。

只用手机时设 `--computer none`；不配置手机时设 `--phone none`（两者不能同时为 `none`）。复用已有可用节点时加 `--network existing`，跳过服务器部署，但仍要核验该节点。默认 `--network self-hosted` 走自建服务器路线。

调整设备、网络方案或免费/订阅目标后，工具会要求重新确认观察记录；它不会修改已有网络、登录状态和免费权益，也不要求重装已可用的配置。

## 使用范围

这是一份操作指导及进度工具，不是账号销售、支付担保或网络安全认证。静态对照能检查步骤和分支是否衔接，不能替代客户设备、网络和实际付款结果的验收。软件界面变化时先核对官方资料；遇到与文档不同的状态先排查，不盲目重复点击。

本仓库不包含真实客户配置、账号资料、购买订单、私人截图，也不收集这些数据。可选面板默认不安装；不默认部署防火墙或进行断网测试。相关软件与商标归各自权利人所有。
